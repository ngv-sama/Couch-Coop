# Code of Conduct

Couch Co-op follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be kind, assume good intent, keep feedback about the work, and make the project welcoming to people of every background and experience level. Harassment, insults and personal attacks are not accepted anywhere the project lives: issues, pull requests, discussions and chat.

## Reporting

If someone's behavior worries you, contact the maintainer privately through GitHub ([@ngv-sama](https://github.com/ngv-sama)). Reports are read promptly and kept confidential. The maintainer may remove comments, lock threads, or block people who break this code, following the Contributor Covenant's enforcement guidelines.
